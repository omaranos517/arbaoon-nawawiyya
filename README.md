# arbaoon-nawawiyya

An Islamic reading app for the Forty Hadith of Imam al-Nawawi, with explanations and narrator biographies.

## Development

### Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
npx cap sync
```
